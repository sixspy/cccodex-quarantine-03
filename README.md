## 回炉钉点（物化包口径）

- **唯一口径**：回炉钉点只走物化包——开跑当刻由服务端一次落定，封存条目键、原因码与载荷指纹（sha256）到 `rework_pins`，回炉列表读数换源到物化包，钉点只读、拒再改；不存在独立凭证双开。
- **排他锁**：`ux_rework_active_row` 部分唯一索引 + `BEGIN IMMEDIATE` 写事务，两个值班并发抢开同一回炉单，只成一单，其余收到短句中文报错。
- **清洗入库闸口**：样本指纹与钉点拧花即拒（`/api/cleaning/intake`），审计留「清洗入库被拒」事件。
- **台参数**：`rework_pin_mode=物化包` 为只读项，服务端对改值返回 403。
- 四屏联动：回炉列表亮「钉点·物化包」徽标，隔离舱卡片亮回炉中计数，抓取详情显样本指纹，审计页留封存/拒收轨迹。
